# Non-Autoregressive Decision Model Simulation

This example demonstrates the core difference between autoregressive and non-autoregressive decision models using a simplified binary classification task. Autoregressive models make sequential decisions where each output depends on previous outputs, while non-autoregressive models make independent decisions for each input, allowing for potential parallelization and faster processing.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
